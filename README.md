# Flask Data Visualization Dashboard 📊

An interactive data dashboard built using **Flask** and **Chart.js** to display visual insights in a clean and modern interface.

This project is part of my learning journey into **backend development** and **data visualization**.

- Interactive charts using Chart.js
- Responsive and minimal UI
- Organized project structure
- Easy to extend with real datasets
